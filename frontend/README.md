# CPU Scheduling Visualizer — Frontend

A professional 10-page React/Vite frontend for a CPU Scheduling Visualizer with FastAPI + Random Forest integration.

## Requirements

- Node.js 18+ (20+ recommended)
- Existing FastAPI backend running at `http://127.0.0.1:8000`

## Windows PowerShell

```powershell
cd frontend
npm install
npm run dev
```

Open the Vite URL printed by the terminal, normally:

```text
http://localhost:5173
```

For a production build:

```powershell
npm run build
npm run preview
```

### Optional API URL

Create `.env` from `.env.example`:

```powershell
Copy-Item .env.example .env
```

Then change:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Pages

1. Dashboard — `/dashboard`
2. Process Management — `/processes`
3. CPU Simulator — `/simulator`
4. Algorithm Comparison — `/comparison`
5. Gantt Chart Visualization — `/gantt`
6. Dataset Management — `/datasets`
7. ML Model Training — `/training`
8. ML Recommendation — `/recommendation`
9. Training History — `/history`
10. About Project — `/about`

## Backend endpoints consumed

Core:
- `GET /`
- `GET /health`
- `POST /simulate`
- `POST /compare`
- `POST /generate-processes`
- `POST /upload`
- `GET /export`

Datasets:
- `POST /datasets/upload`
- `GET /datasets`
- `GET /datasets/{dataset_id}`
- `POST /datasets/{dataset_id}/records`
- `PUT /datasets/{dataset_id}/records/{record_id}`
- `DELETE /datasets/{dataset_id}/records/{record_id}`
- `DELETE /datasets/{dataset_id}`

ML:
- `POST /ml/train`
- `GET /ml/train/{job_id}/status`
- `GET /ml/models`
- `POST /ml/evaluate`
- `POST /ml/recommend`
- `GET /ml/training-history`
- `GET /ml/feature-importance`

## Important integration note

The supplied project brief specifies endpoint names but does not include the actual FastAPI source or response schemas. This frontend therefore uses small normalization layers around the documented endpoints instead of inventing scheduling or ML results. If the backend uses different JSON field names, update the service normalizers in:

- `src/services/schedulerService.js`
- `src/services/datasetService.js`
- `src/services/mlService.js`

No fake metrics or fake ML recommendations are generated by the frontend.
